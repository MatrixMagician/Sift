## Read this before Task 1 — two facts measured 2026-07-27 that supersede RESEARCH.md

RESEARCH.md was written before D-19-17 was added to CONTEXT.md. Where the two disagree, **D-19-17 wins**.
Two figures were measured directly against the shipped analyser during planning; both are facts, not
estimates, and both change what the golden cases can assert.

**M1 — `len(flags) == 0` is unreachable on any non-empty eu-stack dump.**
`analyse_saturation` (`src/sift/pipeline/eustack.py:733-840`) appends the `unclassified_thread_pct` and
`no_resolvable_frame_pct` flags **unconditionally** whenever `analysis.total_threads` is non-zero — the
severity varies, the append does not. Only `lock_convergence_count` is conditional (one flag per
over-threshold `LockSite`; zero lock sites means zero lock flags).
Measured on the REAL healthy reference capture at
`/home/oliverh/Downloads/iserver1_stacks_1-minute_diff/` (first dump, 3,902 threads, 93 signatures):

```
FLAGS: 2
  unclassified_thread_pct   info  1.3  percent
  no_resolvable_frame_pct   info  0.0  percent
lock_sites: []
```

So a real, healthy, near-idle server raises **two** flags. D-19-15's literal `flags == 0` — and ROADMAP
success criterion 2's "raises zero flags" — cannot be satisfied by any input without changing the frozen
Phase-16 analyser, which CONTEXT `<domain>` places explicitly out of scope. RESOLVED before execution: see D-19-18 and the `### D-19-15 amendment (measured 2026-07-27)` heading in 19-CONTEXT.md (option `declared-count`). Task 1 now only verifies that amendment is present.

**M2 — the committed CI derivative cannot be the negative case input as-is.**
Measured on `tests/fixtures/eustack/reference_capture_derivative.txt` (105 threads, 93 signatures):

```
FLAGS: 2
  unclassified_thread_pct   critical  38.1  percent   (warn 5.0, critical 15.0)
  no_resolvable_frame_pct   info       0.0  percent
```

The derivative is signature-faithful but deliberately **not** thread-count-faithful (105 threads standing
in for 3,902), so its unclassified share inflates 1.3% → 38.1% and grades `critical`. Plan 19-03 owns the
consequence: the negative golden case needs its own thread-proportion-faithful derivative.

**M3 — RESEARCH.md "Pattern 4" is superseded.** Its recommendation to engineer the positive fixture so it
also trips `lock_convergence_count`, and to define `hang_detected` as `bool(bundle.saturation.flags)`, is
**rejected by D-19-17** and must not be implemented. D-19-17 records why both alternatives were rejected;
do not reopen it.

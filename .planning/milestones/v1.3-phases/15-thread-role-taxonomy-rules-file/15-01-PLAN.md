<objective>
Prove the whole Phase 15 architecture with ONE thread, end to end, before any expansion.

A raw eu-stack thread block is split into frames by a helper shared from the shipped adapter,
each frame symbol is normalised, the ordered normalised tuple becomes the signature, a packaged
TOML rules file carrying exactly one real rule is loaded and validated, and the classifier returns
`idle-parked` / `job-queue` with the matched pattern text and the frame index it matched at.

Purpose: the loop order (D-01), the normalisation policy (D-05), the frame-sharing seam (D-08) and
the package-data layout (D-16) are the four commitments Phases 16-19 inherit. Proving them on one
path now costs one commit; discovering an architectural dead-end after five layers have landed
costs the phase.

Output: `src/sift/rules/` (package + one-rule TOML), `src/sift/pipeline/eustack.py` (normaliser,
signature, minimal strict models, loader, classifier), `iter_frames()` on the shipped adapter, and
`tests/test_eustack_rules.py` carrying the end-to-end proof.
</objective>

<objective>
Harden the rules loader from the tracer's minimal models into the strict, fail-at-load surface
D-06, D-09 and D-12 specify — and prove success criterion 2 end to end by pointing `rules_path` at
an edited copy and watching a thread change role.

Purpose: this is the house discipline "fail at load, not at use" applied to the one file an engineer
is expected to edit by hand. A misspelt key, a pasted `pthread_cond_timedwait@@GLIBC_2.3.2`, or a
duplicated row must all be errors the moment the file is read — not rules that look present in the
file and are silently dead when it matters.

Output: validators on `Rule` / `RulesMeta` / `ThreadRoleRules`, a hardened `load_rules`, and the
loader's error-path, packaging and override tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| hand-edited rules file -> typed program state | An operator-authored TOML crosses into the classifier's precedence-ordered rule list |
| pattern text -> frame matching | An author-supplied string becomes a substring/prefix/equality test against customer log-derived symbol text |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-15-01 | Tampering | `Rule` / `ThreadRoleRules` validators | medium | mitigate | `extra="forbid"` on every model, `RuleRole` `Literal` excluding `unclassified`, `MatchKind` `Literal`, non-empty-pattern and normalised-pattern `field_validator`s, and a duplicate-pair `model_validator` — every one pinned by a named test in Task 2 |
| T-15-02 | Tampering | `classify_signature` match dispatch | medium | mitigate | D-09's `exact`-by-default with an explicit `match` field: a loose match is never accidental, and every `contains` in the file is greppable in a diff. This is the ADR 0013 bare-substring-collision lesson applied to a surface where a pattern is tested against one symbol rather than 64 KB of arbitrary content |
| T-15-04 | Tampering | `tomllib.loads` on operator-supplied TOML | low | accept | `tomllib` has no tag, anchor or object-construction mechanism — a hostile file can only fail to parse (`ValueError` naming the source) or fail validation, never execute. Canon deserialisation-injection referred to `/gsd-secure-phase` |
| T-15-03 | Information Disclosure | `rules_path` filesystem read | low | accept | Operator-supplied local read path, opened read-only, never written or transmitted; matches ADR 0009's `--kb` precedent. A missing file now raises a `ValueError` naming the path rather than silently reverting to the packaged default, so a failed override cannot masquerade as a successful one |
| T-15-SC | Tampering | package-manager installs | low | accept | This plan installs no external package; no new runtime dependency is permitted anywhere in v1.3 |
</threat_model>

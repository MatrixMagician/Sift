<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Production frame text and rules-file strings → prompt | Attacker-influenceable and curator-controlled text crossing into an LLM prompt. |
| Resolved dump order → progression narrative → model | An ordering fact whose confidence must survive into the prompt, because a wrong order produces real figures in a wrong sequence. |
| Combined fact blocks → un-budgeted prompt prefix | Fact blocks are spliced before `PromptBudget.fit`, which never sees them. |

## STRIDE Threat Register (ASVS L1; blocking severity: high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|

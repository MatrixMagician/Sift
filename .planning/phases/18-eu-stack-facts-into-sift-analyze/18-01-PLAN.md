**A. New leaf module `src/sift/pipeline/eustack_facts.py`** (D-15). Mirror
`perfmon_facts.py`'s module docstring, import shape and helper names. Restate D-01, D-02,
D-03, D-05, D-16, D-17 in the docstring in place of PERF-07's decisions, and carry the
leaf-module sentence forward: this module reads the analyser model tree and the prompt
fragment only, and must not import the prompt-orchestrator or CLI modules — the dependency
runs one way. Declare `_PROMPT_PACKAGE = "sift.prompts"`, `_EUSTACK_FILE = "eustack_facts.md"`,
`_EUSTACK_LINES_SLOT = "<<EUSTACK_LINES>>"`, and `_EXEMPLAR_K = 3` (D-02). Copy
`_load_eustack_fragment()` from `_load_perfmon_fragment()`'s `importlib.resources` idiom, and
copy `_cite_prefix(event_ids: tuple[str, ...], ids: set[str]) -> str` verbatim from
`perfmon_facts._cite_prefix`.

Add three new pure helpers:
- `_signature_event_ids(dump_events: list[Event]) -> dict[tuple[str, ...], list[str]]` —
  for one dump, map `signature_of(event.raw)` to the ascending-sorted list of that signature's
  `event_id`s, skipping events where `event.thread is None`. Feed `signature_of` the `raw`
  field, never `message` (the adapter truncates `message` at `CONDENSED_FRAMES = 5`, so a
  message-derived signature would not match the analyser's).
- `_events_by_dump_in_order(events, dumps) -> list[list[Event]]` — call
  `sift.pipeline.eustack_progression.group_dumps(events)` and index it by each
  `DumpSlice.source_file` in `bundle.progression.dumps` order. Do not re-implement the
  grouping loop.
- `_union_exemplars(frame_tuples, per_dump_sig_ids) -> tuple[str, ...]` — implements D-17:
  UNION every contributing signature's full id list first, sort the union ascending, then take
  the lowest `_EXEMPLAR_K`. Resolve each contributing signature's ids by the
  most-recent-dump-where-present rule — walk `reversed(per_dump_sig_ids)` and take the first
  dump whose map holds that frames tuple — which is the identical idiom
  `eustack_progression.compute_progression` already uses at lines 276-278 to resolve display
  fields, so citation and classification can never disagree about which dump the signature
  means. Return an empty tuple when no contributing signature is present in any dump.

Add the public entry point
`render_eustack_facts(bundle: EustackBundle, events: list[Event]) -> tuple[str, set[str]]`.
Note the deliberate divergence from the sibling single-argument signature: none of the frozen
Phase 15-17 models carries event ids, so the renderer needs the events to re-derive them.
Emptiness gate: return `("", set())` when `bundle.analysis.total_threads == 0` — the true
absence of ingested eu-stack data. **Do NOT gate on `bundle.saturation.flags` being empty**: a
healthy capture raises zero flags and must still render its role-composition block, since
"nothing is flagged" is itself a finding the model should be able to narrate.

Render one line per role that has a non-zero thread count, iterating
`bundle.analysis.threads_by_role` in its own key order (the dict is built zero-filled in a
fixed role order by `analyse_eustack`, so iterating it needs no import of any private role
tuple and is deterministic). For each such role, collect the `frames` tuples of every
`SignatureGroup` in `bundle.analysis.signatures` carrying that role, call `_union_exemplars`
over them, and emit a line of the shape:
`{cite_prefix} eu-stack {role} threads: {threads:,} of {total_threads:,} total threads across {signature_count:,} signatures. ({k} of {threads:,} thread events cited as exemplars)`
— thousands-separated with Python's `:,` format spec (locale-independent, deterministic), with
`{k}` being the true length of the returned exemplar tuple, never a hard-coded three. The
parenthetical is the D-03 sampling disclosure and is load-bearing honesty: both the exemplar
count and the true population must appear. Skip any role whose exemplar tuple is empty — a
line with no `[evt:]` token would be an uncited figure, which the D-05 contract forbids. Route
the role string through `sanitise` before interpolation (V5). Finish with
`_load_eustack_fragment().replace(_EUSTACK_LINES_SLOT, "\n".join(lines))` and the accumulated
id set.

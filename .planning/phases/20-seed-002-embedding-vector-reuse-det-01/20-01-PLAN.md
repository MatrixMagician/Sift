second-run assertion.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator filesystem → `case.db` | The reuse read trusts `chunks.text` and `vectors.embedding` from a file on local disk. |
| inference endpoint → `client.embed` response | Server-returned vectors, already validated for length by the shipped client. |

## STRIDE Threat Register (ASVS L1, block on high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-20-01 | Tampering | `CaseStore.load_vectors_by_text` reading a tampered `case.db` | medium | accept | Stated position: `case.db` is exactly as trusted as the operator's filesystem. It already holds the events, raw blobs, clusters and hypotheses the whole report is rendered from, so an attacker able to rewrite `vectors` can already rewrite the evidence itself — reuse adds no new trust boundary and no new attack surface. Sift is a single-operator local CLI with zero network egress beyond the configured loopback endpoint; there is no multi-tenant or remote-write path to defend. |
| T-20-06 | Tampering | order-dependent dict build in the reuse read | low | mitigate | `ORDER BY chunks.chunk_id` makes the duplicate-text winner deterministic instead of depending on unspecified SQLite row order — a silent nondeterminism in a determinism feature. Pinned by the acceptance grep and by the plan 20-04 adjacency test. |
| T-20-07 | Repudiation | persisted `embedding_new_count` / `embedding_reused_count` | low | mitigate | Both keys are written inside the same transaction as the vectors and chunks they describe, so a rolled-back run cannot leave counts that claim work which was not committed. |
| T-20-SC | Tampering | package-manager installs | n/a | accept | No package-manager install task exists in this phase. `sqlite-vec==0.1.9` is already pinned in `pyproject.toml`/`uv.lock` and was legitimacy-audited in an earlier phase; nothing is added to `pyproject.toml` here (RESEARCH.md §Package Legitimacy Audit: not applicable). |

No threat in this plan is rated high, so the block-on-high gate does not fire.
